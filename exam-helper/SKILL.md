# 国企垃圾考试助力器

## 使用流程

### 0. 前置准备
- 在 Minis 设置中开启 **AccessibilityService** 权限（用于读取屏幕文字）
- 在系统设置中开启 **横幅通知**（用于推送答案，华为/小米等机型需单独设置）
- （可选）上传本地题库文件到工作区，格式见下方

### 1. 用户操作
用户手动打开考试/答题页面（微信小程序、支付宝小程序、考试 App、网页等均可），进入答题界面后通知 AI。

### 2. 读题
AI 通过以下方式获取题目：

```bash
# 读取当前屏幕文本
android-a11y-cli extract text
```

提取后立即分析题目内容，排除界面导航文字（如"返回"、"设置"、"提交"等），识别出题目文本。

### 3. 搜答案（优先级由高到低）

#### ① 本地题库（如用户已上传）
```python
# 模糊匹配
for item in 题库:
    if 题目关键词 in item.题目 or item.题目 in 题目关键词:
        return item.答案
```

> ⏱ 实测：题库搜索 2-5 秒即可推送答案

#### ② 考试宝搜索
```yaml
navigate: https://www.baidu.com/s?wd=考试宝+题目关键词
get_text: 提取搜索结果中的答案
```

#### ③ 百度搜索（考试宝无结果时）
```yaml
navigate: https://www.baidu.com/s?wd=题目关键词
get_text: 提取答案
```

> ⏱ 实测：网络搜索 8-10 秒推送一道题答案，但答案不保真，且每次只能搜索一道题
> ⚠️ 网络搜索可能因网络问题变慢，或搜索多题后罢工，需重新输入提示词

### 4. 推送答案
```bash
android-notification send --title "答案" --body "第X题：选项/答案内容"
```

#### 新题记录位置（由用户选择）
在考试开始前或第一次使用技能时，询问用户：

```
新题答案记录方式：
1. 不记录（每道题都重新搜索，Token 消耗最低）
2. 记录到当前会话（只在本次对话有效，下次考试需要重新搜索）
3. 记录到 memory（持久化保存，以后考试自动命中，但每次对话都加载）
```

> ⚠️ Token 消耗：不记录 < 当前会话 < memory
> memory 方式会将所有新题答案写入 daily log，每次对话加载。

- **题库搜到的题**：不记录（题库已有答案）
- **网络搜到的新题**：按用户选择处理

### 5. 轮询下一题
- 推送发出后 **等 2 秒** 重新读屏
- 如果题号没变（仍在同一题）→ 再等 2 秒后重读
- 如果题号变了（进入下一题）→ 回到步骤 2
- 如果读到聊天界面或桌面（不在考试中）→ 停止轮询

### 6. 用户反馈
- 答案正确：无需操作，自动继续
- 答案错误：用户可打断说"错了"或"下一题"来修正

## 题库文件格式（可选）

上传题库后自动加载，用于提升本地命中率。**题库的保存方式由用户选择：**

| 保存方式 | 说明 | Token 消耗 |
|---------|------|-----------|
| **当前会话** | 只在本次对话中有效，下次需要重新上传 | 低（推荐） |
| **写入 memory** | 持久化保存，后续对话自动加载 | 高（每次对话都加载全部题库） |

> ⚠️ 题库写入 memory 后，每次对话都会加载全部题目到上下文中，Token 消耗较大。
> 建议大题库（>100 题）选择"当前会话"模式，小题库可酌情考虑写入 memory。

**TXT 格式（推荐）：**
```
题目内容|答案内容
中国的首都是哪里|北京
1+1等于几|2
```

**CSV 格式：**
```
题目,答案
中国的首都是哪里,北京
```

**JSON 格式：**
```json
[{"question": "中国的首都是哪里", "answer": "北京"}]
```

## 注意事项
- 题库文件仅在当前会话生效，不持久化
- 本技能**不触碰屏幕任何按钮**，只读题推答案，所有操作由用户手动完成
- 不同机型 AccessibilityService 的兼容性可能不同，如遇读屏失败请检查权限设置
- 横幅通知需系统通知渠道 importance ≥ 4，部分国产机型需在设置中单独开启横幅
- **题库搜索**：本人实测 2-5 秒推送答案
- **网络搜索**：本人实测 8-10 秒推送一道题，但答案不保真，每次只能搜一道
- **已知问题**：软件查了不定数量的题后可能罢工，需重新输入提示词，非 bug
